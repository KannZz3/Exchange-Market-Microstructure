# Parsing and Analyzing Raw Nasdaq TotalView-ITCH 5.0 Market Data

### Single-Stock Limit Order Book Reconstruction and Market Microstructure Analysis

This project builds an end-to-end exchange-level market-data pipeline from raw Nasdaq TotalView-ITCH 5.0 binary messages.

Rather than starting from preprocessed OHLC, trade, or quote data, the project reconstructs the market state directly from the sequence of exchange events:

$$
\text{Raw Binary Feed}
\rightarrow
\text{ITCH Messages}
\rightarrow
\text{Order Lifecycle}
\rightarrow
\text{Limit Order Book}
\rightarrow
\text{Market State}
\rightarrow
\text{Microstructure Analysis}
$$

The first-stage implementation focuses on **AAPL on October 18, 2019**. Restricting the initial study to one liquid security and one trading day allows the entire reconstruction pipeline to be validated before extending the research to multiple securities and longer samples.

---

## 1. Research Question

A conventional trade or OHLC dataset records realized transactions or aggregated prices, but the observable market price is generated by a much richer sequence of order-level events.

The central questions are therefore:

1. Can a raw binary exchange feed be decoded correctly and transformed into a reconstructed limit order book?
2. What market-state variables can be derived directly from that book?
3. Does displayed liquidity imbalance contain information about subsequent short-horizon price movements?
4. Is statistical predictability large enough to imply an immediately executable trading strategy?

The project deliberately separates these questions.

In particular,

$$
\text{Predictive signal}
\neq
\text{Profitable executable strategy}.
$$

## 3. First-Principles Market Reconstruction

A limit order book is not a static dataset. It is a **state variable generated by the ordered sequence of exchange events**.

For an active order \(i\), the minimum required state is

$$
(\text{Order ID},\ \text{Side},\ \text{Price},\ \text{Remaining Shares}).
$$

ITCH messages modify this state sequentially.

### Core message types

| Type | Meaning | Effect |
|---|---|---|
| `R` | Stock Directory | Maps Stock Locate to ticker |
| `A` | Add Order | Creates displayed order |
| `F` | Add Order with MPID | Creates displayed order |
| `E` | Order Executed | Reduces remaining quantity |
| `C` | Executed with Price | Reduces quantity and records execution price |
| `X` | Order Cancel | Partially removes displayed quantity |
| `D` | Order Delete | Removes remaining order |
| `U` | Order Replace | Removes old order and creates new order ID |
| `P` | Non-displayed Trade | Transaction record; does not modify displayed book |
| `Q` | Cross Trade | Auction/cross transaction |
| `B` | Broken Trade | Invalidates a previously reported trade |
| `I` | NOII | Net Order Imbalance Indicator |

Order Reference Numbers link modification messages back to the original displayed order.

Internal prices are stored using the original integer `Price(4)` representation and are converted to decimal prices only when producing analytical outputs. This avoids floating-point errors in price-level matching.

## 4. Pipeline Architecture

```text
S101819-v50.txt.gz
        │
        ▼
BinaryFILE Reader
        │
        ▼
ITCH Message Decoder
        │
        ▼
AAPL Stock-Locate Filter
        │
        ▼
Order Reference Manager
        │
        ▼
Displayed Limit Order Book
        │
        ▼
1-Second Market-State Snapshots
        │
        ├── Best Bid / Best Ask
        ├── Mid-Price
        ├── Bid-Ask Spread
        ├── Best-Level Depth
        ├── Order Book Imbalance
        └── Microprice
        │
        ▼
Trade / Auction Extraction
        │
        ▼
Market Microstructure Analysis
```

### Important implementation choices

**Streaming parsing.**  
The gzip-compressed BinaryFILE is processed message by message rather than decompressed into memory.

**Pre-market reconstruction.**  
Orders arriving before 09:30 are processed because they may remain active when the regular session begins.

**Regular-session sampling.**  
The reconstructed book is sampled once per second over

$$
09{:}30{:}00 \le t < 16{:}00{:}00,
$$

producing exactly

$$
6.5 \times 3600 = 23{,}400
$$

market-state observations.

**Auction handling.**  
Cross Trade (`Q`) messages are retained independently of the continuous-book cutoff so that both the Opening Cross and the post-16:00 Closing Cross are captured.

## 5. Limit Order Book Variables

Let

- \(B_t\): best bid,
- \(A_t\): best ask,
- \(Q_t^b\): displayed shares at the best bid,
- \(Q_t^a\): displayed shares at the best ask.

### Mid-price

$$
M_t=\frac{A_t+B_t}{2}.
$$

### Quoted spread

$$
S_t=A_t-B_t.
$$

Spread in basis points:

$$
S_t^{bps}
=
\frac{A_t-B_t}{M_t}\times10{,}000.
$$

### Top-of-book imbalance

$$
I_t
=
\frac{Q_t^b-Q_t^a}
{Q_t^b+Q_t^a},
\qquad
-1\le I_t\le1.
$$

Interpretation:

- \(I_t>0\): greater displayed depth on the bid,
- \(I_t<0\): greater displayed depth on the ask.

### Microprice

$$
MP_t
=
\frac{
A_tQ_t^b+B_tQ_t^a
}{
Q_t^b+Q_t^a
}.
$$

Unlike the simple midpoint, the microprice shifts toward the side with lower available displayed liquidity and therefore incorporates top-of-book pressure.

## 9. Order Book Imbalance and Future Price Movement

Future midpoint return over horizon \(h\) is defined as

$$
r_{t,t+h}
=
\left(
\frac{M_{t+h}}{M_t}-1
\right)
\times10{,}000
\quad\text{bps}.
$$

Top-of-book imbalance is divided into five states.

| Imbalance State | Observations | Mean OBI | Avg. Future 1s Return | Avg. Future 5s Return |
|---|---:|---:|---:|---:|
| Strong Sell | 4,336 | −0.8315 | **−0.0621 bps** | **−0.0655 bps** |
| Sell | 5,201 | −0.3783 | **−0.0535 bps** | **−0.0584 bps** |
| Neutral | 6,142 | 0.0079 | **+0.0131 bps** | **+0.0219 bps** |
| Buy | 4,166 | 0.3923 | **+0.0575 bps** | **+0.0982 bps** |
| Strong Buy | 3,554 | 0.8452 | **+0.0846 bps** | **+0.1259 bps** |

The conditional mean relationship is almost monotonic:

$$
\text{Strong Sell}
<
\text{Sell}
<
\text{Neutral}
<
\text{Buy}
<
\text{Strong Buy}.
$$

This is the main empirical microstructure result of the project.

A larger displayed bid-side imbalance is associated with a more positive subsequent midpoint movement, while a larger ask-side imbalance is associated with a more negative movement.

However, the **median one-second future return is zero in every imbalance bucket**.

Therefore, imbalance does not deterministically predict the next price movement. Instead, it shifts the **conditional distribution and probability of future price changes**.

## 10. Continuous Predictive Relationships

The full-sample correlations are:

$$
Corr(I_t,r_{t,t+1s})
=
\mathbf{0.1016},
$$

$$
Corr(I_t,r_{t,t+5s})
=
\mathbf{0.0626}.
$$

The relationship weakens when the horizon increases from one to five seconds, suggesting that much of the information contained in top-of-book imbalance is short-lived.

Microprice contains slightly more short-horizon information:

$$
Corr
\left(
\frac{MP_t-M_t}{M_t},
r_{t,t+1s}
\right)
=
\mathbf{0.1161}.
$$

Thus, liquidity-weighted price information performs somewhat better than raw imbalance alone in this sample.

These correlations are economically interesting but remain small in absolute explanatory power. Most one-second price variation is not explained by the current top-of-book state.

## 12. Economic and Trading Interpretation

The analysis reveals a critical distinction between **statistical predictability** and **economic tradability**.

For example, the Strong Buy imbalance state produces an average one-second future midpoint return of approximately

$$
0.0846\text{ bps}.
$$

The average quoted spread during the session is approximately

$$
0.8289\text{ bps}.
$$

Therefore,

$$
\frac{0.0846}{0.8289}
\approx
10\%.
$$

The average directional midpoint effect is only about one-tenth of the quoted spread.

Consequently, the observed imbalance relationship should **not** be interpreted as a standalone market-order trading strategy. Crossing the spread would generally dominate the average predicted price movement even before accounting for:

- exchange fees,
- latency,
- slippage,
- queue position,
- incomplete fills,
- adverse selection.

The more plausible applications are therefore microstructure-aware decisions such as:

### Quote skew

Use imbalance or microprice to move the internal fair value away from the simple midpoint.

### Adverse-selection control

Reduce passive sell exposure when the book is strongly bid-heavy, or passive buy exposure when the book is strongly ask-heavy.

### Execution timing

Condition execution aggressiveness on short-lived liquidity pressure rather than treating every market state identically.

These applications remain hypotheses for further testing; they are not established profitable strategies from this single-day sample.

## 13. Key Conclusion

The principal result is not merely that order-book imbalance correlates with future returns.

The deeper result is the complete reconstruction chain:

$$
\boxed{
\text{Raw Exchange Bytes}
\rightarrow
\text{Events}
\rightarrow
\text{Orders}
\rightarrow
\text{Market State}
\rightarrow
\text{Predictive Information}
}
$$

The experiment demonstrates that information absent from ordinary trade or OHLC data can be recovered directly from exchange-level event data.

For AAPL on October 18, 2019:

1. the ITCH event stream can be reconstructed into an internally consistent displayed limit order book;
2. top-of-book liquidity imbalance contains measurable short-horizon directional information;
3. microprice contains slightly more one-second information than raw imbalance;
4. the statistical signal is materially smaller than the transaction-cost scale represented by the bid-ask spread;
5. the signal is therefore better interpreted as a market-making/execution feature than as standalone aggressive directional alpha.

## 14. Limitations

This first-stage study intentionally has a narrow scope.

### Sample limitation

The empirical results come from:

- one stock,
- one trading day,
- one exchange.

They should not be interpreted as universal market relationships.

### Exchange coverage

Nasdaq TotalView describes Nasdaq order-book activity, not the entire consolidated U.S. equity market.

### Sampling

The book is sampled once per second. Event-time dynamics occurring inside each one-second interval are compressed.

### Book depth

The current predictive analysis uses top-of-book depth rather than a complete multi-level order-flow representation.

### Execution realism

The project does not yet model:

- fees,
- rebates,
- latency,
- queue priority,
- partial fills,
- market impact,
- inventory constraints.

Therefore, predictive relationships are not equivalent to executable strategy returns.

Extend the current reconstruction to:

$$

### Phase II — Multi-Stock / Multi-Day Validation

The next stage expands from

$$
1\ \text{stock}\times1\ \text{day}
$$

to

$$
N\ \text{stocks}\times T\ \text{days}.
$$

Large-scale datasets such as WRDS TAQ can then be used for external validation of related market-quality variables including:

- quoted spread,
- effective spread,
- realized spread,
- price impact,
- volume,
- volatility,
- NBBO dynamics.

Because TAQ and ITCH have different information sets, the large-sample extension should validate comparable economic relationships rather than treating TAQ as a replacement for full order-level ITCH reconstruction.
